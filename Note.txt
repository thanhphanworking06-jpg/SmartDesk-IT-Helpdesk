1. Flask là gì?
Flask là một Python web framework giúp bạn xây dựng website bằng Python.

Trong project của chúng ta:
- Python: Xử lý logic của hệ thống.
- Flask: Kết nối Python với website.
- HTML/CSS: Hiển thị giao diện.
- SQLite: Lưu thông tin người dùng và tickets.
Ví dụ, khi người dùng nhấn nút tạo ticket, Flask sẽ nhận thông tin và chuyển cho Python xử lý trước khi lưu vào database.

2.SQLite là gì
SQLite là một hệ quản trị cơ sở dữ liệu nhỏ gọn. Khác với MySQL hoặc PostgreSQL, bạn không cần cài đặt database server riêng.

SQLite lưu dữ liệu vào một file, ví dụ helpdesk.db.
